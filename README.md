# Blue Whale 3D

A React + Three.js halftone whale animation with GPU particle shaders, a travelling swimming wave, independent tail motion, blinking eye, ambient particles and pointer parallax.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

This is an image-derived 2.5D particle reconstruction, not a scan-derived anatomical 3D mesh.
